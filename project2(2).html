Poetry Word Choice Analysis¶

Topic Overview¶

Writing as an art is an expression of creativity. It is a means for escapism, expression, self-realization, and perspective change. Today, computer scientists are trying to map what drives writing and whether creative writing can be emulated by machines.

This project focuses on how creative writing —specifically poetry, where each word is essential— differs from normal language use to understand the implications for a machine learning driven future.

Questions to Address¶

  1. How does language use by poets differ from normal language use?
  2. How does language use differ between poets?
  3. What are the common topics explored by poets?
  4. How does topic choice differ between poets?
  5. How common are poets' topics to average word use?
  6. Would LLMs be able to emulate poetry well?

Dataset Explored¶

This analysis uses two datasets:

  • Poetry Foundation dataset: a collection of poems taken from the Poetry Foundation website; it includes poem, poet, and tag columns. This supports analysis of word frequency, language patterns, and theme frequency.
  • Web word frequency dataset: general language frequency from common web usage, used as a baseline for comparison.

These datasets can show how poetic language differs from everyday language.

This prepares the poetry data set by separating the tags and words in the poem and adding a normalized word count (to correct for dataset size). It also removes all the stop words from both data sets (word like "the").

In [3]:
import string
from sklearn.feature_extraction.text import ENGLISH_STOP_WORDS

poetry["words"] = (poetry["Poem"].str.lower().str.replace(f"[{string.punctuation}]", "", regex=True).str.split())
poetry["words"] = poetry["words"].apply(lambda words: [word for word in words if word not in ENGLISH_STOP_WORDS])
frequency = frequency[~frequency["word"].isin(ENGLISH_STOP_WORDS)]

poetry["word_count"] = poetry["words"].str.len()
poetry["vocab_size"] = poetry["words"].apply(lambda x: len(set(x)))
poetry["normalized_word_count"] = poetry["vocab_size"] / poetry["word_count"]

poetry["tag_list"] = poetry["Tags"].fillna("").str.lower().str.split(",")

Question 1 Exploration: How does language use by poets differ from normal language use?¶

This code creates a normalized ranking (out of one) for both the web and poetry datasets' word frequency. It then plots the poetry's rankings of its top words against the web's rankings, where lower rankings are more common (other than zero).

In [5]:
import matplotlib.pyplot as plt
from collections import Counter
import numpy as np

words = [word for words in poetry["words"] for word in words]
word_count = Counter(words)
word_rank_poetry = {word:num for num,(word,_) in enumerate(word_count.most_common(),1)}

#this takes each word, count pairing in the web data set and auto assigns it a rank in a dictionary based on it's sorting from largest to smallest
word_rank_web = {word: rank
    for rank, (word, _) in enumerate(sorted(zip(frequency["word"], frequency["count"]),key=lambda x: x[1], reverse=True), 1)
}

#makes top tag list; I removed the emdash manually because it thought it was a word
top = [word for word,_ in word_count.most_common(36) if '—' not in word]

#this normalizes the ranks from 0 to 1, where 0 is more common
#the normalization is only out of the words shown, the 20 most frequent poetry non-stop words
poetry_ranks = np.array([word_rank_poetry[word] for word in top])
web_ranks = np.array([word_rank_web.get(word, len(word_rank_web)) for word in top])
poetry_ranks = poetry_ranks / poetry_ranks.max()
web_ranks = web_ranks / web_ranks.max()

#plotting bar graph
x = range(len(top))
plt.figure()
plt.bar(x, poetry_ranks, label="Poetry Normalized Rank")
plt.bar(x, web_ranks, alpha=0.7, label="Web Normalized Rank")
plt.xticks(x, top, rotation=90)
plt.ylabel("Normalized Rank (lower more common other than 0)")
plt.title("Word Rank Comparison")
plt.legend()
plt.show()

Question 1 Interpretation:¶

Poetry and web language are different in word preference. Old words like “thy” and “thou” are common in poetry but rare in web usage. Poetry also tends to emphasize more abstract or sensory language (light, color, emotion). Words like “like,” “said,” and “just” are frequent in both general use and poetry. Thus, poetry favors more expressive and abstract vocabulary while still using some common functional words.

poets = poetry["Poet"].value_counts().head(6).index
fig, axes = plt.subplots(2, 3, figsize=(12, 8))
axes = axes.flatten()

for i, poet in enumerate(poets):

    #gets all the words for this poet (as each poem has a list of words and each poet has multiple poems)
    poet_words = [word for poem in poetry[poetry["Poet"] == poet]["words"]
        for word in poem]

    #word frequency for top ten words
    word_count = Counter(poet_words)
    top_words = word_count.most_common(10)
    words = [word for word, _ in top_words]
    counts = [count for _, count in top_words]

    #plot
    axes[i].bar(words, counts)
    axes[i].set_title(poet)
    axes[i].tick_params(axis="x", rotation=90)

#plot list of bar graphs (all poets)
plt.suptitle("Most Common Words by Poet", fontsize=14)
plt.tight_layout()
plt.show()

Question 2 Interpretation:¶

Poem length varies much between poets, ignoring stop words (roughly 100-400 words). This can be taken as either some poets are using more stop words or some poets have longer poems. The two are likely correlated; having a longer poem requires more connecting, or stop, words. Poem length likely varies more than displayed to account for that. But there is no golden poem length below as certain amount of words.

The most common words per poet of the poets listed were more similar than I expected. They were mostly focused on common verbs, old words, light, nature, and some punctuation. This is more comparing all the graphs rather than each two to each other. So, there does seem to be an average poet word focus, but the per graph word arrangements are distinct. There are universally common words like "like" but the arrangement of words is distinct.

Question 5 Exploration: How common are poets' topics to average word use?¶

In [10]:
#converts frequency dataset to a a dictionary word:count
web_frequency = dict(zip(frequency["word"], frequency["count"]))

total_web = sum(web_frequency.values())
top_tags = [tag for tag, _ in tag_count.most_common(15)]
tag_scores = []
web_scores = []

#creating poetry tag frequency scores and web tag frequency scores
for tag in top_tags:

    tag_scores.append(tag_count[tag])

    #finding average web frequency for words in the tag
    words_in_tag = tag.split()
    web_score = 0
    valid = 0
    for word in words_in_tag:
        if word in web_frequency and word!='&':
            web_score += web_frequency[word]
            valid += 1
    web_scores.append(web_score / valid if valid > 0 else 0)

#normalizing scores out of one; this is normalized out of the tags shown, not all of them
tag_scores = np.array(tag_scores)
web_scores = np.array(web_scores)
tag_scores = tag_scores / tag_scores.max()
web_scores = web_scores / (web_scores.max() if web_scores.max() > 0 else 1)

#plotting
x = np.arange(len(top_tags))
plt.figure()
plt.bar(x, tag_scores, label="Normalized Poetry Tag Frequency")
plt.bar(x, web_scores, alpha=0.5, label="Normalized Web Tag Frequency")
plt.xticks(x, top_tags, rotation=90)
plt.title("Poetry Topic Frequency")
plt.legend()
plt.show()

Question 5 Interpretation:¶

The distribution of tag frequencies are fairly dissimilar to each other. Interestingly, out of the tags shown, poetry and the web both have a favorite by far. Poetry favors the living topic, and the web favors time and brevity. The most common poetry topics are not the most common web topics. Essentially, most people care about different things than poets, or at least, write about different things.

Question 7 Exploration/Interpretation: Would LLMs be able to emulate poetry well?¶

Yes and no. LLMs come to a conclusion based on the most probable next chunk of text to occur. There does seem to be an "average" poet; the most common words per poet reoccur frequently (like "like" or "day"), as well as topic - "living" seems to be a commonly used topic for most poets, for instance. However the set of word frequency per poet and favored topics differs. And, there are a lot of topic not tagged that the poets seem to use more than the tagged topics. So I guess I would say LLMs would be able to make something that resembles a poem, but would fail at creating the distinct voice that defines a poet.
